# StoryVerse SEO GEO AEO Framework v1.0

## Goal

StoryVerse should be readable by humans and understandable by search engines and AI answer engines.

## SEO

Each page should include:

- Clear title
- Meta description
- H1
- H2 structure
- Internal links
- Related content
- Clean URL slug

## GEO

Generative Engine Optimization means pages should be easy for AI systems to quote, summarize, and reference.

Each important page should include:

- Short answer block
- Clear summary
- FAQ
- Structured sections
- Direct definitions
- Context-rich paragraphs

## AEO

Answer Engine Optimization means pages should answer specific questions clearly.

Recommended blocks:

- What is this story about?
- Who is the main character?
- What genre is it?
- Where should I start reading?
- What is the reading order?

## Journal Strategy

Journal is the long-term traffic engine.

Topics:

- Writing process
- Character creation
- Worldbuilding
- AI translation
- How to write better stories
- Reading recommendations

## Page Rule

Every page should serve both readers and AI discovery.
