# StoryVerse Design System v1.0

## Vision

StoryVerse is not only a novel website. It is an original IP platform designed for reading, storytelling, global publishing, and long-term brand expansion.

## Design Philosophy

Apple x Notion x Medium x Netflix.

Keywords:

- Minimal
- Elegant
- Premium
- Reading First
- Content First
- Whitespace
- Long-term

## Core Principles

1. Reading comes first.
2. Content is more important than decoration.
3. One design language must be used across every page.
4. Components must be reusable.
5. Every page should feel like part of the same product.
6. Design once. Reuse forever.

## Logo

Use a wordmark only.

```text
StoryVerse
```

Recommended tagline:

```text
Build Worlds.
```

Logo rules:

- No mascot
- No fantasy icon
- No dragon
- No book icon
- No feather icon
- No complex symbol
- Simple typography only

## Layout

| Rule | Value |
|---|---:|
| Maximum width | 1400px |
| Reading width | 820px |
| Section spacing | 120px |
| Grid | 12 columns |

## Page Rhythm

Every page must follow the same reading rhythm:

```text
Hero
↓
Summary
↓
Main Content
↓
Related Content
↓
Call To Action
↓
Footer
```

## Buttons

Use only three button types:

- Primary: purple filled
- Secondary: white background
- Ghost: text only

## Image Style

Use a consistent cinematic concept-art style.

Rules:

- Soft light
- Minimal composition
- No stock-photo feeling
- No cartoon screenshot style
- No busy background
- No unrelated decorative image

## Icon System

Use Lucide Icons only.

## Cards

| Rule | Value |
|---|---|
| Radius | 16px |
| Border | `#ECECEC` |
| Shadow | Very light |

## Motion

Motion must be subtle:

- Fade
- Gentle scale
- No heavy animation
- No autoplay video
- No distracting effects

## Navigation

Maximum six top navigation items:

```text
Home
Stories
Journal
About
Collaborate
Contact
```

## Reading First Rule

Every design decision must answer one question:

> Does this improve reading?

If not, remove it.

## Long-term Rule

Version 1: simple.

Version 2: better.

Version 3: powerful.

Never redesign from scratch. Always evolve.
