# StoryVerse Fan Growth System v1.0

## Principle

Readers should not only follow stories. They should follow the creator's journey.

## Growth Channels

- Website
- Journal
- Newsletter
- YouTube
- Social media
- Community

## Weekly Content Rhythm

Suggested rhythm:

| Day | Content |
|---|---|
| Monday | Story update |
| Wednesday | Creation journal |
| Friday | Character or worldbuilding note |
| Saturday | Behind-the-scenes content |
| Sunday | Newsletter |

## Home Page Growth Entrances

The home page should guide visitors into three actions:

- Read stories
- Know the creator
- Join the journey

## Journey Module

Recommended daily or weekly update examples:

- Words written
- Chapter completed
- Character created
- Translation progress
- New idea recorded

## Reader Habit Rule

Make readers feel that something is growing every week.
