# StoryVerse AI Workflow v1.0

## Principle

Do not create too many agents in V1.

The first version only needs four AI functions:

```text
Polish
Translate
SEO
Publish
```

## Workflow

1. Author writes original content.
2. AI polishes the text while preserving the author's voice.
3. AI translates the content into target languages.
4. AI creates SEO/GEO/AEO metadata.
5. Human reviews important outputs.
6. Content is published.

## AI Functions

### Polish

Goal: improve clarity, rhythm, and emotional expression without changing the original idea.

### Translate

Target languages:

- English
- Japanese

Future languages can be added later.

### SEO

Generate:

- Meta title
- Meta description
- H1
- FAQ
- Related content suggestions
- Structured content summary

### Publish

Prepare final page-ready content for the website.

## Human Review Rule

AI can assist, but publishing decisions should stay under human control.
