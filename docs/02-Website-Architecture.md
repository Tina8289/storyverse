# StoryVerse Website Architecture v1.0

## Main Navigation

- Home
- Stories
- Journal
- About
- Contact

Future optional item:

- Collaborate

## Home

Purpose: present StoryVerse as an original IP platform and guide visitors into reading.

Sections:

1. Hero
2. Featured Story
3. Latest Stories
4. Writing Journey
5. About StoryVerse
6. Newsletter
7. Footer

Primary CTA:

- Start Reading

Secondary CTA:

- Follow the Journey

## Stories

Purpose: list all stories and categories.

Categories:

- Fantasy
- Sci-Fi
- Romance
- Adventure

Sections:

1. Hero
2. Category Filters
3. Story Grid
4. Featured Series
5. Newsletter
6. Footer

## Story Detail

Purpose: make each story readable, expandable, and SEO/AEO friendly.

Sections:

1. Hero
2. Story Summary
3. Start Reading
4. Table of Contents
5. Main Content
6. Previous Story
7. Next Story
8. More Stories
9. Newsletter
10. Footer

## Journal

Purpose: become the long-term SEO/GEO/AEO traffic entry.

Content types:

- Writing process
- Character creation
- Worldbuilding notes
- AI translation notes
- Lessons learned
- Reading reflections

## About

Purpose: explain the dream, values, and journey, not a corporate profile.

Sections:

1. Hero
2. Why StoryVerse Exists
3. Creator Journey
4. Values
5. Future Vision
6. Footer

## Contact

Purpose: simple contact page.

Sections:

1. Hero
2. Email
3. Collaboration note
4. Footer

## Shared Page Rhythm

All pages follow:

```text
Hero
Summary
Main Content
Related Content
CTA
Footer
```
