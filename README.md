# StoryVerse

## Vision
Build a global original story platform where a Chinese writer creates in Chinese and AI helps publish to the world.

## V1 Goal
Launch a simple, expandable platform:
- Home
- Stories
- About
- Blog
- Contact
- Chinese / English / Japanese

## Tech Stack
- Next.js
- Vercel
- Supabase
- ChatGPT (translation & writing assistance)

## Development Principles
1. Launch first.
2. Keep it simple.
3. Design for future expansion.
4. One story, many content assets.
5. AI assists creators, it does not replace them.
